Projet POO : location de voitures
Projet de POO en Java Swing, ISGI Sfax, 2 LIG-BI, 2026-2027. Réalisé par Lina Triki et Mahdi Zayani.

Ce projet est une application avec des fenêtres pour gérer une agence de location de voitures. Pour l'instant nous avons terminé la fenêtre principale et l'interface de la fenêtre de réservation. La fenêtre principale affiche le titre et quatre boutons : nouvelle réservation, gestion des voitures, gestion des réservations et quitter. Le bouton "Nouvelle réservation" ouvre déjà sa fenêtre. Dans cette fenêtre, nous avons construit tout le formulaire : les champs nom, prénom et téléphone, la liste des catégories (Économique, Classique, Luxe), la liste des voitures, le champ de la durée, les quatre cases à cocher pour les services, le bouton Calculer, les champs où s'afficheront le total, la réduction et le total à payer, et les boutons Confirmer et Annuler. Nous avons aussi créé une classe BoutonStyle qui hérite de JButton, pour que tous les boutons de l'application aient le même style sans le répéter à chaque fois.

Pour les données, nous avons choisi MySQL plutôt que des fichiers texte, parce que nous allons en avoir besoin au semestre 2. Nous avons installé MySQL, créé la base location_voitures, ajouté le driver Java dans le dossier lib, et écrit la classe Connexion qui ouvre la connexion à la base. Nous l'avons testée avec la petite classe TestConnexion, que nous supprimerons à la fin du projet.

Pour lancer l'application, il faut ouvrir le dossier projet_java dans IntelliJ (nous utilisons le JDK 25), ajouter le fichier .jar du dossier lib comme bibliothèque avec un clic droit puis "Add as Library", et lancer la classe Main. La fenêtre principale s'ouvre alors. Pour la connexion à la base, MySQL doit être installé et démarré, et le mot de passe se règle dans le fichier dao/Connexion.java.

Le code est rangé en quatre packages. À la racine de src, Main.java est le point de départ de l'application. Le package view contient toutes les fenêtres : FenetrePrincipale, FenetreNouvelleReservation et BoutonStyle, qui sont écrites, ainsi que FenetreGestionVoitures, DialogVoiture et FenetreGestionReservations, qui sont créées dans le projet et qui serviront respectivement à gérer les voitures, à ajouter ou modifier une voiture, et à consulter les réservations. Le package dao contient Connexion, qui est écrite, ainsi que VoitureDAO et ReservationDAO, créées pour accueillir les requêtes sur les voitures et sur les réservations. Les packages model et service sont prêts à recevoir les classes de données et de calcul. Nous avons séparé le code comme ça pour que les fenêtres ne contiennent que de l'affichage, et que la base de données et les calculs soient ailleurs, ce qui rend le projet plus facile à comprendre et à modifier.
